# Фотоконтент сайту

Заглушки `[ФОТО: …]` у макетах і темі — це список кадрів, яких бракує.
Тут він зібраний у шотліст із готовими промптами й конвеєром, який
доводить кадр від генерації до сторінки.

| Файл | Що робить |
|---|---|
| `style.md` | візуальна мова: світло, оптика, колір, що не має бути в кадрі |
| `shotlist.json` | 29 унікальних кадрів: промпт, пропорції, роздільність, де стоїть |
| `mapping.json` | текст заглушки в `docs/*.html` → кадр і його `alt` |
| `wp-map.json` | кадр → запис і поле у WordPress |
| `generate.py` | генерує кадри через Gemini Image API у `out/` |
| `prompts.py` | друкує готовий однорядковий промпт для чату Gemini |
| `pull.py` | дістає кадр із дампа `javascript_tool` у `out/` |
| `apply.py` | зменшує їх у `docs/assets/photos/` і міняє заглушки на `<img>` |
| `import.php` + `import-wp.sh` | заливає в медіатеку WP і розставляє по полях |

`out/` і `.env` — поза git: майстри важкі, ключ не місце в репозиторії.

## Як прогнати

Потрібен ключ Gemini з [aistudio.google.com](https://aistudio.google.com/apikey).
Поклади його у `photos/.env` **своїми руками** (файл у `.gitignore`):

```
GEMINI_API_KEY=...
```

Скрипти ключ ніде не друкують і нікуди не відправляють, крім самого API.

```bash
python3 generate.py --list                  # побачити шотліст
python3 generate.py                         # згенерувати все, чого немає
python3 generate.py --only hero-home --force  # перезняти один кадр
python3 apply.py --check                    # що є, чого бракує
python3 apply.py                            # поставити в макети
./import-wp.sh                              # залити в локальний WordPress
REMOTE=root@78.46.233.40 ./import-wp.sh     # у тестову копію
```

`generate.py --flash` бере дешевшу модель — годиться, щоб швидко подивитися
композицію, перш ніж замовляти 4K.

## Якщо ключа немає: через чат Gemini у браузері

Набір від 2026-11-25 знятий саме так — у вбудованому браузері, без API.
Шлях неочевидний, тому записую, як він працює.

```bash
python3 prompts.py hero-home     # промпт у буфер очей, вставити в чат Gemini
```

Картинку зі сторінки **не можна** ні завантажити (панель браузера нікуди
не кладе файл), ні скопіювати в буфер macOS, ні відправити на локальний
сервер: Chrome ріже запити зі сторінки в локальну мережу, а ізольований
світ розширення не бачить `blob:`-адрес сторінки.

Що працює: перемалювати `<img>` у canvas і віддати base64 назовні.
Вивід більший за ліміт інструмент сам скидає у файл повз контекст моделі —
звідти його й забирає `pull.py`.

```js
// у консолі сторінки Gemini
const img = [...document.querySelectorAll('img')]
  .filter(i => i.naturalWidth >= 512).pop();
const W = Math.min(img.naturalWidth, 1600), H = Math.round(img.naturalHeight * W / img.naturalWidth);
const c = document.createElement('canvas'); c.width = W; c.height = H;
c.getContext('2d').drawImage(img, 0, 0, W, H);
window.__fr = c.toDataURL('image/jpeg', 0.84).split(',')[1];
```

```bash
python3 pull.py hero-home        # бере найсвіжіший дамп і кладе в out/
```

Обмеження цього шляху: немає seed і немає керування роздільністю.
Gemini віддає 1493×640 для 21:9 і 1344×756 для 16:9 — цього вистачає
для вебу, але серію з однаковим мотоциклом так не зняти.

## Два правила, на яких тримається результат

**Місце головного обʼєкта.** У широких банерах (21:9) зліва лягає темна
заливка з заголовком. Тому в промптах явно написано, що мотоцикліст —
у правій половині, а ліва лишається спокійною. Якщо переписувати промпт,
цю вимогу треба зберегти, інакше текст сяде на обличчя.

**Один акцентний колір.** Екіпірування чорне з вставками Kawasaki Green
`#69BE28`. У старих макетах замовника подекуди кислотно-жовтий — це
попередня палітра, повторювати її не треба.

## Чого тут немає і не буде

Портрети засновника й інструкторів, аватарка цитати на головній
і кадри відеовідгуків — це конкретні живі люди. Згенероване обличчя
під справжнім імʼям вводить відвідувача в оману, тож такі слоти
позначені `"real": true` і чекають на фото від школи.

Поки їх немає, у шотлісті є нейтральна заміна: `rider-anon-1`,
`rider-anon-2` і `video-still-pad` — мотоцикліст у шоломі з опущеним
склом, обличчя не видно. Ці кадри ставляться тимчасово, щоб сторінка
не світила порожніми плашками, і підлягають заміні.

Повний перелік — у `shotlist.json`, ключ `real_photos_needed`.
