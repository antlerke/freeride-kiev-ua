# freeride.kiev.ua

Новий сайт мотошколи FreeRide (Київ) і, згодом, веб-застосунок для картки учня.

## Структура

| Шлях | Що це |
|---|---|
| `docs/` | Сайт. Звідси публікується GitHub Pages |
| `brief/` | ТЗ і референси. **Не в git** — див. `.gitignore` |
| `app/` | Застосунок Rider Card (з'явиться пізніше) |

## Публікація

GitHub Pages: гілка `main`, тека `/docs`.

## Джерело вимог

`brief/MASTER-BLUEPRINT.md` — ТЗ v1.1 на сайт, інтеграцію з Appointer
та особистий кабінет учня. `brief/refs/` — приклади сторінок від замовника.

Бриф лежить поза git навмисно: репозиторій публічний, щоб працював Pages,
а ТЗ містить прайс, бізнес-логіку та план інтеграції з CRM.
